Energy Report deployment copy-paste commands
============================================

Use this plain text file for terminal copy/paste.
Do not copy long commands from the PDF when a command contains long URLs,
heredocs, or line continuations.

Current recommended operator flow
---------------------------------

B1. Fresh bootstrap + month-end smoke for 2025-05-31
B2. Change anchor to Sunday 2025-05-18 and run again
B3. Reset anchor back to blank scheduled mode
B4. Only after B3, install or adjust systemd timer
B5. Use the helper commands below for update / clean reinstall / rollback

Important notes
---------------

- Default final output dir: /srv/energy-report-output
- Default staging dir during runtime: /srv/energy-report-output/_staging
- After a successful run, staging files are auto-cleaned and the empty `_staging` folder is removed
- The one-command bootstrap below intentionally uses the deploy branch:
  backup-before-pdf-docs-20260426
- That branch currently contains deploy-flow fixes newer than the older reviewed
  tag v4.3.0-dev
- B1 intentionally does NOT install systemd yet, because the anchor is pinned for
  smoke testing
- Only install or enable the timer after B3 has restored:
  REPORT_ANCHOR_DATE=


B1 - Fresh bootstrap + month-end smoke (Daily + Monthly)
--------------------------------------------------------

curl -fsSL "https://raw.githubusercontent.com/trantuyen1991/ETL_EMS_REPORT/backup-before-pdf-docs-20260426/deploy/bootstrap_ubuntu_host.sh" | sudo bash -s -- --mysql-host 192.168.100.82 --mysql-database bms_db --mysql-user admin --mysql-password admin --anchor-date 2025-05-31 --reset-project

Check what was deployed:

sudo -u energy-report -H bash -lc 'cd /srv/energy-report && git rev-parse --short HEAD'
grep '^REPORT_ANCHOR_DATE=' /srv/energy-report/config/.env
find /srv/energy-report-output -path '/srv/energy-report-output/_staging' -prune -o -type f -print | sort | tail -n 30

Expected idea for B1:
- Daily artifacts for 2025-05-31 under /srv/energy-report-output/2025_05/
- Monthly artifacts for 2025-05-31 under /srv/energy-report-output/2025_05/
- Temporary print files are auto-cleaned after successful copy-back
- No timer installed yet


B2 - Change anchor to Sunday and run again (Daily + Weekly)
-----------------------------------------------------------

sudo sed -i 's|^REPORT_ANCHOR_DATE=.*|REPORT_ANCHOR_DATE=2025-05-18|' /srv/energy-report/config/.env
grep '^REPORT_ANCHOR_DATE=' /srv/energy-report/config/.env

cd /srv/energy-report
sudo -u energy-report ./venv/bin/python -m src.main
find /srv/energy-report-output -path '/srv/energy-report-output/_staging' -prune -o -type f -print | sort | tail -n 30

Expected idea for B2:
- Daily artifacts for 2025-05-18 under /srv/energy-report-output/2025_05/
- Weekly artifacts for 2025-05-18 under /srv/energy-report-output/2025_05/


B3 - Reset to scheduled mode
----------------------------

sudo sed -i 's|^REPORT_ANCHOR_DATE=.*|REPORT_ANCHOR_DATE=|' /srv/energy-report/config/.env
grep '^REPORT_ANCHOR_DATE=' /srv/energy-report/config/.env

Expected result:
- REPORT_ANCHOR_DATE=


B4 - Install systemd service and timer only after B3
----------------------------------------------------

cd /srv/energy-report
sudo ./deploy/systemd/install_systemd_units.sh

Check service and timer:

sudo systemctl status energy-report-etl.service --no-pager
sudo systemctl status energy-report-etl.timer --no-pager
systemctl list-timers energy-report-etl.timer --all
journalctl -u energy-report-etl.service -n 100 --no-pager
find /srv/energy-report-output -path '/srv/energy-report-output/_staging' -prune -o -type f -print | sort | tail -n 30


B4.1 - Change the timer schedule later
--------------------------------------

sudo nano /etc/systemd/system/energy-report-etl.timer

Find this line:
OnCalendar=*-*-* 23:00:00

After editing, reload and restart the timer:

sudo systemctl daemon-reload
sudo systemctl restart energy-report-etl.timer
systemctl list-timers energy-report-etl.timer --all


B5 - Update to the latest deploy branch
---------------------------------------

cd /srv/energy-report
sudo -u energy-report git fetch origin
sudo -u energy-report git checkout backup-before-pdf-docs-20260426
sudo -u energy-report git pull --ff-only origin backup-before-pdf-docs-20260426
sudo -u energy-report ./venv/bin/pip install -r requirements.txt
sudo -u energy-report ./venv/bin/python -m src.main

If systemd unit files changed in the repo, re-install them:

cd /srv/energy-report
sudo ./deploy/systemd/install_systemd_units.sh

Check the current deployed commit:

cd /srv/energy-report
sudo -u energy-report git log -1 --oneline


Clean reinstall from zero
-------------------------

Stop timer first if it already exists:

sudo systemctl disable --now energy-report-etl.timer || true
sudo rm -f /etc/systemd/system/energy-report-etl.service /etc/systemd/system/energy-report-etl.timer || true
sudo systemctl daemon-reload

Remove project and outputs:

sudo rm -rf /srv/energy-report /srv/energy-report-output

Then run B1 again.


Re-run only the bootstrap from scratch on a test host
-----------------------------------------------------

curl -fsSL "https://raw.githubusercontent.com/trantuyen1991/ETL_EMS_REPORT/backup-before-pdf-docs-20260426/deploy/bootstrap_ubuntu_host.sh" | sudo bash -s -- --mysql-host 192.168.100.82 --mysql-database bms_db --mysql-user admin --mysql-password admin --anchor-date 2025-05-31 --reset-project

Use this when you want to recreate the project root quickly without manually doing Step B2 or B4.


Roll back and run an older version/tag
--------------------------------------

Example: run the older reviewed tag v4.3.0-dev

cd /srv/energy-report
sudo systemctl disable --now energy-report-etl.timer || true
sudo -u energy-report git fetch --tags origin
sudo -u energy-report git checkout --force v4.3.0-dev
sudo -u energy-report ./venv/bin/pip install -r requirements.txt

If the old tag complains about missing Sensor Monitoring outline icons, apply the fallback links:

sudo -u energy-report bash -lc '
set -e
cd /srv/energy-report/src/templates/assets/icon/outline
ln -sf ../sensor/capacity.svg snowflake.svg
ln -sf ../sensor/flow.svg wind.svg
ln -sf ../steam.svg flame.svg
ln -sf ../water.svg droplet.svg
ln -sf ../energy.svg activity.svg
ln -sf ../sensor/power.svg bell.svg
ln -sf ../sensor/pressure.svg gauge.svg
ln -sf ../sensor/temperature.svg thermometer.svg
ln -sf ../sensor/power.svg alert-circle.svg
ln -sf ../sensor/power.svg circle-check.svg
'

Set a smoke anchor and run the old version once:

sudo sed -i 's|^REPORT_ANCHOR_DATE=.*|REPORT_ANCHOR_DATE=2025-05-31|' /srv/energy-report/config/.env
cd /srv/energy-report
sudo -u energy-report ./venv/bin/python -m src.main
find /srv/energy-report-output -path '/srv/energy-report-output/_staging' -prune -o -type f -print | sort | tail -n 30

When done, return to the current deploy branch:

cd /srv/energy-report
sudo -u energy-report git checkout backup-before-pdf-docs-20260426
sudo -u energy-report git pull --ff-only origin backup-before-pdf-docs-20260426
sudo -u energy-report ./venv/bin/pip install -r requirements.txt
sudo sed -i 's|^REPORT_ANCHOR_DATE=.*|REPORT_ANCHOR_DATE=|' /srv/energy-report/config/.env
